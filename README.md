# Task 2 – Exploratory Data Analysis (EDA)

This repository contains the work for Task 2 of the internship.  
The task focuses on performing Exploratory Data Analysis (EDA) on the Titanic dataset.

---

## 📌 Files Included
- **Task2_EDA.ipynb** – Complete Jupyter Notebook containing all EDA steps and visualizations  
- **titanic.csv** – Dataset used for analysis  
- **eda_used_titanic.csv** – Output dataset generated after running the notebook (upload after running)

---

## 📌 Steps Performed in EDA

### 1. Importing Libraries
Used essential Python libraries:  
`pandas`, `numpy`, `seaborn`, `matplotlib`.

### 2. Loading Dataset
The dataset `titanic.csv` was loaded into a DataFrame for analysis.

### 3. Dataset Overview
- Viewed dataset info  
- Calculated summary statistics  
- Counted missing values  
- Inspected overall structure  

### 4. Visual Exploration
Generated different visualizations for better understanding:
- Histogram of Age & Fare  
- Boxplot of Age & Fare  
- Correlation heatmap  
- Pairplot on a sampled subset  

### 5. Saving Processed Dataset
A processed copy of the dataset was saved as:  
**`eda_used_titanic.csv`**
